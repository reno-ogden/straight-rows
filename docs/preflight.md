## Hard constraints

- **Lock:** Sat Nov 14, 2026, 4:00 pm CT (22:00 UTC). A PR opened *or pushed to* after that is late.
- **Individual work.** Any language, internet, and AI assistants allowed; I must explain and defend every line.
- **Submission PR changes exactly one file:** `submissions/reno-ogden/submission.json` in a fork of
  `Bluestaq/ndsu-hackathon-submissions`. Don't open it early (submissions are public).
- **Public repo at submit time**, owned by me, and `repository_url` must point to it.
- **No email address or student ID** anywhere in `submission.json` (validator rejects them).
- **Scored window:** detections must start in 2026-05-06T00:00Z – 2026-05-07T00:00Z (simulated dates);
  end must be after start and no later than 2026-05-07T00:00Z.

## Deliverables

- [ ] `submission.json`: `participant.github_handle`, `repository_url`, non-empty `detections`;
      each with `start`, `end` (ISO 8601 with timezone), `tractors` (T1/T2/T3), `class`, `action`,
      `confidence` (0–1), `evidence` (non-empty list of checkable strings).
- [ ] Generated by code, and `python src/validate_submission.py <file>` prints `OK`.
- [ ] README: exact setup + run commands, pinned dependencies, the command that regenerates
      `submission.json`, approach, how labeled data was used, failure modes, limitations,
      and what extra farm/SDA data would help. Document how to obtain the dataset.
- [ ] 5-minute demo + 3 minutes Q&A: show an episode with its evidence, cause and action,
      an ambiguous case or limitation, and how the code reproduces the submitted output.
      Judges may ask me to explain or modify code live.
